# Pierwsza wiadomość do Claude Code

Skopiuj wszystko poniżej linii i wklej jako pierwszą wiadomość w Claude Code (aplikacja desktopowa, folder `ejdawid-overlay`).

---

Cześć. To repo overlayu mojego streamu. Najpierw przeczytaj `CLAUDE.md` i `docs/spec-overlay.md`, obejrzyj obrazki w `docs/ref/`.

Zrób kawałek 1 z sekcji 9 speki:
1. `overlay.js`, `overlay.css` i `index.html` w najprostszej wersji: na ekranie napis „overlay działa” + tryb z `fieldData.mode`.
2. `se/loader.html` i `se/fields.json` (na razie tylko pole `mode`).
3. Pomóż mi włączyć GitHub Pages dla tego repo i wypchnąć kod (prowadź mnie krok po kroku, mam słabą znajomość gita).
4. Prowadź mnie krok po kroku przez wklejenie loadera w StreamElements (Custom Widget) i dodanie overlayu jako Browser Source w OBS.

Cel: sprawdzić, czy SE wczytuje skrypt z GitHub Pages. Jeśli nie, przejdź na zapas ze speki (kod wklejony w SE) i powiedz mi, co to zmienia.

Nie rób jeszcze pasków ani alertów. Po teście powiedz, co działa i co jest następne.
